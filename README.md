# Password Authentication System

Система парольной аутентификации с хешированием Argon2id, защитой от перебора и поддержкой сессий.

---

## Описание

Клиент-серверное приложение для регистрации и входа пользователей. Пароли не хранятся в открытом виде — используется криптостойкое хеширование Argon2id на стороне клиента. Сервер хранит только хеши и соли в базе данных SQLite.

**Лабораторная работа по дисциплине «Информационная безопасность».**

---

## Функциональность

### Аутентификация
- Регистрация нового пользователя
- Вход по логину и паролю
- Единый ответ при ошибке входа (защита от enumeration)
- Поддержание сессии после входа (session_id, 30 минут)

### Безопасность
- Хеширование пароля на клиенте (Argon2id, 256 бит)
- Уникальная соль для каждого пользователя
- Rate limiting: 5 неудачных попыток → блокировка на 5 минут
- Timestamp: защита от replay-атак (3 секунды)
- Валидация пароля через zxcvbn (словари, qwerty, даты)
- Словарь русских клавиатурных сочетаний (`йцукен`, `фывапр`, `ячсмит`)
- Поддержка UTF-8, пробелов в пароле
- Защищённый эндпоинт `/profile` с проверкой сессии

### Юнит-тесты
- 21 тест (Google Test)
- Покрытие: парсинг JSON, timestamp, rate limiting, сессии

## Установка и запуск

### Требования
- Visual Studio 2022 (с компонентом «Разработка классических приложений на C++»)
- Google Test Adapter (через Visual Studio Installer)
- Современный браузер (Chrome, Firefox, Edge)

### Запуск сервера

1. Откройте `Server/Server.sln` в Visual Studio.
2. Дождитесь загрузки решения.
3. Нажмите `Локальный отладчик Windows`.
4. В консоли увидите:

```
========================================
Запуск сервера аутентификации...
Хеширование: Argon2id
База данных подключена
Таблица users готова
========================================
Сервер запущен на http://localhost:8080
Нажмите Ctrl+C для остановки
```

**Важно:** не закрывайте консоль. Сервер должен работать во время тестирования.

### Запуск клиента

1. Откройте `Website/index.html` в браузере.

### Запуск юнит-тестов

1. Откройте `Server/Server.sln`.
2. Меню Тест → Запуск всех тестов (`Ctrl+R, A`).
3. Результат: 21 Пройден.

## Использование

### Регистрация

1. Откройте сайт в браузере.
2. Введите логин (4–16 символов, латиница + цифры).
3. Введите пароль (8–128 символов, минимум: буквы + цифры + спецсимвол).
4. Нажмите «Зарегистрироваться».
5. Пароль хешируется на клиенте, на сервер уходят только хеш и соль.

### Вход

1. Введите логин и пароль.
2. Нажмите «Войти».
3. Клиент запрашивает соль у сервера → хеширует пароль → отправляет хеш.
4. Сервер сравнивает хеши и возвращает результат.
5. При успехе — создаётся `session_id` (сохраняется в localStorage).

### Проверка профиля (защищённый эндпоинт)

В консоли браузера:

```javascript
await fetchProfile()
// → OK: Вы вошли как <ваш_логин>
```
